# Lab Task 3 - JUnit Unit Testing (Temperature Converter)

## Objective
Introduce unit testing in Java using JUnit within NetBeans IDE.

## What I implemented
- TemperatureConverter class with celsiusToFahrenheit, fahrenheitToCelsius, celsiusToKelvin methods.
- JUnit 5 tests covering known conversion pairs, round-trip conversion, and boundary values.

## How to run
1. Open the project in NetBeans.
2. Right-click TemperatureConverterTest.java → Test File.
3. View results in the Test Results panel.
